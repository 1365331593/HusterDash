============================================
    HusterDash 使用文档
============================================

【项目简介】
HusterDash 是一款无尽跑酷游戏。玩家在无限延伸的道路上向前奔跑，躲避
不同方向驶来的电动车。碰撞即游戏结束，记录并持久化最佳里程。

开发环境：Unity 2022.3.62f3c1 LTS
渲染管线：Universal Render Pipeline (URP)

============================================
【如何打开与运行】
============================================

1. 安装 Unity Hub，添加 Unity 2022.3.62f3c1 版本。
2. 在 Unity Hub 中点击"打开"→ 选择 HusterDash/ 文件夹。
3. 项目加载后，打开 Assets/Scenes/Splash.unity。
4. 点击顶部 Play 按钮即可从头运行完整流程。

   场景流转：Splash（开屏动画）→ MainMenu（主菜单）→ Game（核心玩法）

   也可直接打开 MainMenu.unity 或 Game.unity 单独调试单个场景。
   注意：直接运行 Game.unity 会跳过开屏动画和主菜单。

============================================
【操作说明】
============================================

■ MainMenu 场景（第三人称自由视角）
  WASD          移动角色
  鼠标移动      旋转视角
  鼠标右键      切换行走/奔跑
  鼠标滚轮      缩放相机
  左 Alt        按住临时解锁鼠标光标
  F 键          在触发区域内按下，开始游戏/打开新手教学
  Esc           退出游戏（弹出确认面板）

■ Game 场景（俯视角核心玩法）
  WASD          移动玩家
  鼠标右键      切换行走/奔跑
  Esc           暂停/恢复游戏
  左 Alt        按住临时解锁鼠标光标（暂停时无效）

■ 暂停菜单
  Esc 键或点击左上角暂停图标按钮可打开暂停面板：
    "继续游戏"   - 恢复游戏
    "回主菜单"   - 带淡入淡出过渡返回 MainMenu
    "清空成绩"   - 弹出确认弹窗，确认后删除历史最佳记录

■ 游戏结束
  碰撞车辆后游戏结束，弹出失败面板：
    "重新开始"   - 重新加载 Game 场景
    "回主菜单"   - 返回 MainMenu

============================================
【游戏规则】
============================================

- 玩家沿道路向前（+Z 方向）奔跑，道路无限生成。
- 每隔 2 米（2 个道路块），车辆行驶方向交替一次。
- 车辆从道路两侧驶来，玩家需左右躲避。
- 碰到任何车辆即游戏结束。
- 行进距离（里程）实时显示，打破历史最佳记录时有提示。
- 行走速度 3 m/s，奔跑速度 6 m/s。

============================================
【构建项目】
============================================

1. 菜单 File → Build Settings。
2. 确保场景列表按顺序排列（已在 EditorBuildSettings 中配置）：
     索引 0: Splash.unity
     索引 1: MainMenu.unity
     索引 2: Game.unity
3. 选择目标平台（Windows/Mac/Linux），点击 Build。
4. 选择输出目录，等待构建完成。

   注意：Splash 必须作为首发场景，确保 URP 管线正确初始化。

============================================
【依赖包】
============================================

以下包通过 Unity Package Manager 安装（已在 manifest.json 中配置）：
- Cinemachine 2.10.7          （第三人称虚拟相机）
- Input System 1.14.2          （新版输入系统）
- TextMeshPro                  （文字渲染）
- Universal RP                 （URP 渲染管线）
- Unity Test Framework 1.1.33  （测试框架）

============================================
【数据存储】
============================================

- 历史最佳里程存储在 PlayerPrefs 中，键名 "BestDistance"。
- 清空成绩功能会同时删除 PlayerPrefs 和内存缓存。
- 卸载游戏不会删除 PlayerPrefs 数据（系统级存储）。

============================================
【常见问题】
============================================

Q: 直接打开 Game.unity 运行，场景很暗？
A: 必须从 Splash.unity 启动，Splash 是 URP 管线首发场景，负责
   正确初始化渲染设置。构建时 Splash 索引必须为 0。

Q: 主菜单中走进触发区域，无法按 F 键？
A: 检查 PlayerInput 组件是否正确配置，Input System 是否启用。
   同时确保 EventSystem 使用 InputSystemUIInputModule。

Q: 暂停后光标不见了？
A: 暂停时系统会解锁光标，如果仍然不见，按左 Alt 试试。

Q: 如何修改行走/奔跑速度？
A: 在 Game.unity 场景中选中 Player，在 Inspector 中找到
   PlayerMove 组件，修改 Walk Speed 和 Run Speed。

Q: 如何修改音乐音量？
A: 在 MainMenu 场景中，场景右侧有音量设置面板（音符按钮），
   可调节主音量。AudioMixer 资产位于 Assets/Audio/。

Q: 如何运行测试？
A: Window → General → Test Runner，选择 PlayMode 或 EditMode
   标签页运行。

Q: 新手教学如何触发？
A: 在 MainMenu 场景中，走到发光触发区域，滚轮切换到"新手教学"
   选项，按 F 键打开。

Q: 构建后运行崩溃？
A: 确保构建场景顺序正确（Splash → MainMenu → Game），
   且 Splash.unity 中 RenderSettings 的关键参数与后续场景一致。

│   ├── Scenes/              # 场景文件
│   │   ├── Splash.unity     # 开屏动画
│   │   ├── MainMenu.unity   # 主菜单（3D 自由探索）
│   │   └── Game.unity       # 核心玩法
│   ├── Scripts/
│   │   ├── Splash/          # 开屏动画脚本
│   │   ├── MainMenu/        # 主菜单脚本
│   │   ├── Game/            # 核心玩法脚本
│   │   └── Common/          # 公共脚本（场景过渡等）
│   ├── Shaders/             # 自定义 Shader
│   │   ├── PortalVortex.shader   # 传送门漩涡
│   │   ├── GlowingBorder.shader  # 发光边框
│   │   └── FogWall.shader        # 雾墙
│   ├── Settings/            # URP 渲染质量设置
│   ├── Audio/               # 音频资源
│   └── Prefabs/             # 预制体
├── Packages/                # 包清单
└── ProjectSettings/         # 项目设置
